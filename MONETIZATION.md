# Монетизация Lumen Chain

> These numbers are a design sketch. There is no live network, no fee revenue, and no payout mechanism. The devnet in the README uses a public validator key and an internal USDC balance. Do not treat the commands below as a way to earn money.



## 5 способов заработка

### 1. Валидатор / стейкинг

- **Минимум:** 10 000 LMN
- **Доход:** 3% годовых от комиссий сети, начисляются за каждый предложенный блок
- **Условия:** узел онлайн, ключ публичен, ≥ 2/3 валидаторов подтверждают блок
- **Риск:** slash при двойном подписывании (негативная награда)

```bash
lumen stake 10000
lumen node --port=8789
```

### 2. LP-провайдер (ликвидность AMM)

- **Доход:** 0.30% от оборота пула LMN/USDC
- **Комиссия:** остаётся в пуле, перераспределяется по доле LP
- **Как добавить:** `ledger.addLiquidity("LMN", "USDC", baseAmount, quoteAmount)`

### 3. Keeper-оператор

- **Доход:** 0.5% сервисного сбора с каждой своп-операции (USDC → LMN)
- **Ср. объём:** зависит от inflows в казну; настройки политики — `minAmount`, `maxPerSwap`, `maxPerDay`
- **Инфраструктура:** любой VPS с доступом к Base RPC
- **Прозрачность:** все сделки журналируются в `~/.lumen/keeper-state.json`

```bash
lumen keeper run   # автономный режим
```

### 4. Реферальная программа

- **Ставка:** 5% от всех x402-комиссий, сгенерированных привлечённым вами трафиком
- **Валюта выплат:** USDC на Base, раз в 7 дней
- **Как участвовать:** получить реферальный код в кабинете партнёра, делить ссылку
- **Отслеживание:** открытый лог по адресу казны; реферальные выплаты видны в on-chain истории

### 5. API-хостинг (x402)

- **Модель:** HTTP 402 — оплата за вызов в USDC, без аккаунтов и ключей
- **Ценовые листы:**

| Эндпоинт | Цена за вызов |
|---|---|
| `lumen_blockNumber` | $0.001 |
| `lumen_getBalance` | $0.002 |
| `lumen_getBlock` | $0.002 |
| `lumen_quoteSwap` | $0.005 |
| `lumen_sendRawTransaction` | $0.01 |
| Inference-вызовы (LLM, image) | $0.01–$0.50 по тарифу модели |

- **Как подключить:** запустить `lumen serve`, настроить `LUMEN_X402_PRICE_USDC`
- **Пример:** 10 000 вызовов/день по $0.002 = $20/день ≈ $600/мес

```bash
export LUMEN_RPC_PORT=8899
export LUMEN_X402_PRICE_USDC=2000   # 0.002 USDC за вызов (6 знаков)
lumen serve --port=$LUMEN_RPC_PORT
```

## Награды за стейкинг

- **Источник дохода:** комиссии транзакций сети (0.001 LMN/tx) + комиссия AMM (0.30%)
- **Не инфляция:** новых LMN не создаётся — доход формируется перераспределением существующих комиссий между валидаторами и LP
- **Расчёт:** награда пропорциональна `stake / totalStake` за каждый блок
- **Farming:** дополнительные истемы в пулах — через DAO-предложения (в разработке)

---

## Заработок keeper-оператора

- **Сервисный сбор:** 0.5% (50 bps) от суммы свопа на каждом цикле
- **Пример:** keeper купил LMN на 1000 USDC → сервисный сбор = 5 USDC, на Lumen-адрес зачисляется эквивалент в LMN
- **Ограничения:** политика `minAmount` / `maxPerSwap` / `maxPerDay` защищает от проскальзывания и дневных лимитов
- **Прозрачность:** журнал `keeper-state.json` с историей всех сделок (до 200 последних)
