# Roadmap Lumen

## v0.1 (сейчас)

- [x] ed25519-аккаунты, base58check-адреса
- [x] Реестр: переводы, стейкинг, анстейкинг
- [x] PoS-консенсус, продюсер по весу, финальность 2/3
- [x] Merkle-корень, state root, проверка блоков
- [x] Встроенный AMM (x·y=k, 0.3%)
- [x] JSON-RPC + CLI
- [x] Keeper: автоконвертация USDC/ETH → LMN
- [x] Контракты LMN (ERC-20 + permit) и LumenAMM для Base
- [x] 10 тестов

## v0.2

- [ ] P2P-слой: gossip, peer discovery, синхронизация
- [ ] Доли LP в AMM (безопасный withdraw)
- [ ] Очередь nonce в keeper'е
- [ ] Смарт-контракты в самой цепи (минимальная VM)
- [ ] Explorer: блоки, транзакции, графики

## v0.3

- [ ] Кросс-чейн мост: Base ↔ Lumen (с проверкой на стороне Lumen)
- [ ] Атомические свопы BTC/LTC через HTLC
- [ ] Stealth-адреса и подписи с адаптерами (Ledger, Trezor)
- [ ] Аудит (issue с меткой `audit`)
