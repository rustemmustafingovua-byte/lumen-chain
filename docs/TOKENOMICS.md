# Токеномика Lumen

## Эмиссия

| Параметр | Значение |
|---|---|
| Общее предложение | 1 000 000 000 LMN (6 знаков) |
| Инфляция | 3% годовых, делится на валидаторов |
| Халвинг | каждые 4 года инфляция делится пополам |
| Минимальный стейк | 10 000 LMN |
| Комиссия транзакции | 0.001 LMN (1000 единиц) |
| Комиссия AMM | 0.30% — остаётся LP |
| Премайн | 60% (600M) на казну, 40% (400M) — ранним валидаторам |

## Распределение премайна

| Назначение | Доля | Зачем |
|---|---|---|
| Казна (gensis) | 600M LMN | ликвидность AMM, награды, гранты контрибьюторам |
| Ранние валидаторы | 400M LMN | выплачивается 1:1 к застейканному: кто первым застейкал, тот получил столько же в подарок из пула |

## Точный механизм премайна

```
chain.genesis():
  TREASURY_ADDRESS            <- 600 000 000 LMN   (60%)
  EARLY_VALIDATORS_ADDRESS    <- 400 000 000 LMN   (40%)

стейк 10 000 LMN:
  счёт теряет 10 000 LMN (становятся stake) + комиссию
  пул ранних валидаторов отдаёт стейкеру 10 000 LMN (1:1)
  итого баланс падает только на комиссию, а stake растёт
```

Пул конечен: как только он исчерпан, бонсы прекращаются, и дальше работают
только 3% годовых. Никаких разблокировок и дедлайнов.

Адреса генезиса выводятся детерминированно из seed-строк
`lumen/genesis/treasury` и `lumen/genesis/early-validators` — их можно
пересчитать и проверить.

## Как генерируется доход

```
комиссии транзакций ─┐
награды за стейкинг  ─┼→ в пулы AMM → комиссия 0.3% → LP (владельцы пула)
комиссия AMM         ─┘
```

## Почему нет «перепродажи»

- Фиксированная эмиссия: инфляция известна заранее и проверяема.
- Премайн на казне продаётся **только** через AMM — то есть по рыночной цене,
  а не по внутренней.
- Нет разблокировок, нет сроков, нет «собрать 30% на биржу» — нечего дампить.

## Риски для держателя

| Риск | Митигация |
|---|---|
| Мало ликвидности | keeper доливает пул автоматически; можно добавить свой пул |
| Валидаторы сходятся | PoS со 2/3-финальностью; ключи публичны и проверяемы |
| Код с багом | тесты + аудит-приглашение (issues labelled 💰 Reward) |
| Регуляторный риск | токен не даёт доступа к активам и не обеспечивает доходность — это utility, а не инвестиция |
