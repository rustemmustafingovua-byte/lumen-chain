# Как финансируется Lumen

## Источники

| Источник | Куда идёт | Размер |
|---|---|---|
| USDC на Base → `0x8aC6a229f254980CCd3Dd35CF5E1B7c08880B40E` | казна: ликвидность AMM, гранты, CI | любой |
| GitHub Sponsors | операционные расходы (CI, домены, аудит) | $5–50/мес |
| Issues labelled 💰 Reward | выплата тому, чей PR влился | $20–200 за issue |

## Экономика для держателя

- Держать LMN: staking даёт ~3% годовых.
- Холдеры пула LMN/USDC получают 0.3% с оборота.
- Keeper конвертирует поступающие USDC/ETH в LMN по рыночной цене — цена
  определяется формулой AMM, а не биржевым ордербуком.

## Модель «без биржи»

```
вы отправляете USDC ──► Base ──► keeper ──► AMM ──► LMN ──► ваш Lumen-адрес
вы хотите выйти   ──► LMN   ──► keeper ──► AMM ──► USDC ──► ваш Base-адрес
```

Ни на одном шаге не требуется аккаунт на бирже, KYC или подпись третьей
стороной: подписывает ваш кошелёк, а keeper — это обычный процесс с ключом,
который может запустить кто угодно.

## Что нужно, чтобы экономика заработала

1. **Ликвидность в пуле** — премайн казны наполняет AMM; keeper поддерживает баланс.
2. **Валидаторы** — любой может запустить узел при 10 000 LMN.
3. **Пользователи API** — Lumen-узел может отдавать бесплатные инференс-инструменты,
   оплачиваемые x402 в USDC (как в [agent-x402](https://github.com/rustemmustafingovua-byte/agent-x402)).
4. **Аудит** — issue с меткой `audit`; оплата контрибьюторам.

## Честно

Стоимость токена определяется ликвидностью и спросом, а не кодом. Код здесь —
не более чем точка отсчёта: он делает активство проверяемым, а рынок —
самостоятельным. Всё остальное — распределение, ликвидность и люди.
