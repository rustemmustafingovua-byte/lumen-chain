Lumen · LMN

A proof-of-stake chain that ships with its own market

Stake it, swap anything into it, and leave — without ever touching an exchange. MIT, no VC, auditable in an afternoon.

View on GitHub Architecture

What is in the box

core/ed25519 accounts, PoS consensus, Merkle blocks, native AMM, JSON-RPC
cli/lumen — wallet, node, transfers, staking, swaps, explorer
keeper/autonomous converter: any asset → LMN and back, no exchange
contracts/LMN as ERC-20 on Base plus the on-chain AMM

Quickstart

git clone https://github.com/rustemmustafingovua-byte/lumen-chain
cd lumen-chain && npm install && npm test

npx tsx cli/lumen.ts wallet new     # create a wallet
npx tsx cli/lumen.ts node            # run a validator node
npx tsx keeper/keeper.ts scan        # what the keeper sees

Tokenomics

Supply1,000,000,000 LMN, fixed, no mint after genesis
Emission3% per year to validators, halving every 4 years
Minimum stake10,000 LMN
Transaction fee0.001 LMN
AMM fee0.30% to liquidity providers
Premine60% treasury, 40% early validators
